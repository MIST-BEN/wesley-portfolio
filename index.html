关于About

我学的是材料成型及控制工程，研究怎样让材料成为需要的形状。写前端，是同一件事的另一面：让复杂的逻辑，成为清楚、自然、好用的界面。

从好奇开始，通过动手深入。读书期间，我通过自主学习与项目实践进入前端领域，持续探索如何让复杂的软件更容易理解和使用。

我关注界面，也关注界面背后的结构：数据如何流动、状态如何组织，以及工具之间的操作是否连贯。

工作方式How I work

  1. 1

    清晰的结构

    先让结构清晰，再让功能增长。

    把组件、界面状态与服务端数据分开组织，明确每一部分的职责，让变化有处可去。

    React · TypeScript

  2. 2

    有序的数据

    状态各有归属，变化有迹可循。

    区分本地交互状态与远端数据的生命周期，再为实时消息安排清楚的更新路径。

    Zustand · React Query · WebSocket

  3. 3

    连贯的体验

    让每个操作，都有自然的下一步。

    从列表浏览到拖拽表单，从开发到调试，围绕实际任务组织交互，关注等待、反馈和衔接。

    Virtual scrolling · React DnD · Electron
